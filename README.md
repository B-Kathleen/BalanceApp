# BalanceApp
This project is a streamlined weight-tracking mobile application developed in Android Studio using Java. The primary goal of the application is to provide users with a simple way to create a personal profile, establish a goal weight, and record and manage their weight over time. The application uses a database to store user profile and weight information, allowing users to securely access and manage their data across the application. Core functionality includes account creation and authentication, goal-weight management, daily weight entry, viewing historical weight data, and editing or deleting previously entered information. 

Developing UI design frameworks during the planning stage was essential to determining which screens, features, and navigation elements were necessary for the finished application. The primary screens were designed around the user's most common tasks: creating an account, logging in, viewing current and goal weight information, entering a new weight, and managing historical weight data. 

I approached the development process incrementally, beginning with the application's UI structure and then implementing the functionality behind each screen. Creating UI designs and frameworks before completing the application helped establish the required screens and provided a visual reference while coding. I separated responsibilities between different components of the application, including activity classes for individual screens, XML layouts for the user interface, and a DatabaseHelper.java class for managing stored data. This organization made it easier to identify and modify individual portions of the application during development. 

One of the most significant challenges occurred during the implementation of the application's customized toolbar and navigation menu. The original approach required additional configuration and troubleshooting to ensure that the toolbar displayed correctly across the application's screens. Rather than continuing with a complicated implementation, I reevaluated the approach and used Android Studio's toolbar resources. 

The component I was particularly successful in developing was the application's weight database and grid-based weight history display. The database stores user and weight information, while DatabaseHelper.java manages the operations required to retrieve and modify that information. The main activity then retrieves the stored weight data and presents it to the user in an organized four-column grid containing the date, weight, edit, and delete options. This allowed me to demonstrate my understanding of database interaction, Java programming, Android UI development, and the connection between stored data and interactive interface elements.
